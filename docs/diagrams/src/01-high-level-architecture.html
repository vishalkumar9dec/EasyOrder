EasyOrder Server · FastAPI

API layer

  • /api/whatsapp/webhook — verify + signature, route intent
  • /api/session/* — bootstrap, cart edits, checkout
  • /api/me/* — OTP login, orders, profile, spend
  • /api/r/* — short links used in chat copy

2Intent router

Regex classification into intent families before any model call — greetings, targeted order, history, privacy, unsupported.

3LangGraph agent

guardrails → intent parser → profile defaults → Swiggy workers → guardrails → persist

Order scheduler

Background task, 30s poll. Places scheduled orders at target_placement_at and notifies the host.
